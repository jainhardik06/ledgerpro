## Available Reports

Money OS provides six core report types:

| Report | What It Shows |
|---|---|
| **Expense Summary** | Total spending by category over any period |
| **Income Summary** | Total income by source or client |
| **Budget vs. Actual** | Planned vs. real spending per budget |
| **Client P&L** | Revenue, expenses, and margin per client |
| **Tax Summary** | Categorized expenses grouped for tax filing |
| **Cash Flow** | Monthly income minus expenses, over time |

Navigate to **Reports** in the left sidebar to access all report types.

---

## Expense Summary Report

The most-used report. Answers: *Where did the money go?*

**Configuration:**
- **Date range** — Any period from a single day to multiple years
- **Group by** — Category (default), month, week, or day
- **Filter** — Include/exclude specific categories, clients, or tags

**Export options:**
- CSV — For spreadsheet analysis
- PDF — For accountants or stakeholders

The report includes:
1. Total spend for the period
2. Top 5 categories by spend (ranked)
3. Full category breakdown table (amount + % of total)
4. Month-over-month comparison (if multi-month range selected)

## Income Summary Report

Answers: *Where did the money come from?*

Groups income transactions by:
- **Source** — If transactions have different income categories (Consulting, Products, Royalties)
- **Client** — If transactions are tagged to clients
- **Month** — Time-series view

---

## Tax Summary Report

Built for annual tax preparation. Export this and hand it to your accountant.

The Tax Summary shows:
- All expense categories with totals
- Transactions flagged as tax-deductible (based on category rules)
- Income totals by category
- A "tax-deductible summary" table pre-formatted for Schedule C (US) or equivalent

**Setting up tax categories:**
Go to **Settings → Categories** and toggle which categories are tax-deductible. Money OS applies these rules to all existing and future transactions in that category.

## Client P&L Report

Answers: *Is this client profitable?*

For each client, the report shows:
- **Revenue** — Transactions tagged to this client as income
- **Expenses** — Transactions tagged to this client as expenses
- **Margin** — Revenue minus expenses
- **Margin %** — Margin as a percentage of revenue

Use this report quarterly to identify:
- Clients where your margins are below your target
- Clients generating the most absolute profit
- Clients with high expenses relative to revenue

## Exporting Data

All reports support CSV export. Additionally:

**Full data export**: Settings → Data → Export All Data. Generates a ZIP file containing every transaction as a CSV, categorized by year.

**Accounting software export**: Settings → Integrations → Export for [QuickBooks / Xero / Tally]. Generates a formatted file importable into these tools.
