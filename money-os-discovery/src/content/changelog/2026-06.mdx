The headline this release is **budget alerts**. Set a monthly limit on any category and Money OS emails you when you cross 80% and again at 100% — so overspending becomes something you catch in real time instead of discovering at month-end.

CSV import also got smarter: it now remembers how you mapped a given bank's columns, so the second and every later import from that bank is effectively one click.
