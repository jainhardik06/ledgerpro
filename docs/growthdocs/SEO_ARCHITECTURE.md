# SEO Architecture

> **Scope**: Technical SEO, on-page SEO, schema markup, crawlability, and indexing strategy for the Money OS Discovery Ecosystem. This covers both the Astro discovery site and AI-crawler optimization.

---

## 1. SEO Philosophy

We do not optimize for algorithms. We optimize for humans, and the algorithm follows.

**Three non-negotiable SEO principles:**

1. **Speed over decoration** — Lighthouse 90+ on every page. Slow pages do not rank.
2. **Structure over density** — One `<h1>`, clear hierarchy, semantic HTML. No keyword stuffing.
3. **Answer before you pitch** — Satisfy the user's search intent completely before any CTA.

## 2. Technical SEO Foundation

### 2.1 Meta Tags (every page)

```html
<title>{title} | Money OS</title>
<meta name="description" content="{description}" />
<meta name="keywords" content="{keywords}" />
<link rel="canonical" href="{canonicalUrl}" />

<!-- Open Graph -->
<meta property="og:title" content="{title}" />
<meta property="og:description" content="{description}" />
<meta property="og:image" content="/og/{slug}.png" />
<meta property="og:url" content="{canonicalUrl}" />
<meta property="og:type" content="article" />

<!-- Twitter -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="{title}" />
<meta name="twitter:description" content="{description}" />
<meta name="twitter:image" content="/og/{slug}.png" />
```

### 2.2 Robots.txt

```
User-agent: *
Allow: /

User-agent: GPTBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: PerplexityBot
Allow: /

Sitemap: https://discovermoneyos.webasthetic.in/sitemap.xml
```

We explicitly allow AI crawlers. This is the opposite of what most sites do, and it is correct — AI citation is the new backlink.

### 2.3 Sitemap

Auto-generated by Astro's `@astrojs/sitemap` integration.

- Includes all `/blog/*`, `/docs/*`, `/changelog/*`, `/comparisons/*`, `/use-cases/*`, `/resources/*`
- Excludes: draft content, admin routes, 404 pages
- Format: XML, auto-submitted to Google Search Console on deploy

### 2.4 Canonical URLs

Every page sets `rel="canonical"`. Rules:
- Blog pages: canonical = published URL, never pagination URL
- Tag/Category pages: canonical = tag page, individual articles self-canonical
- Duplicate content risk: comparison pages have unique angles — no duplicate risk

### 2.5 Hreflang

Not required in v1. Evaluate after reaching 10,000 monthly visitors with evidence of non-English traffic.

## 3. On-Page SEO System

### 3.1 Heading Hierarchy

Every page must follow this strictly:

```
H1: Primary keyword phrase (once per page)
H2: Major section headings (3–7 per article)
H3: Sub-sections under H2s
H4: Rare. Only inside deep technical docs.
```

### 3.2 Keyword Placement Rules

| Location | Target |
|---|---|
| `<title>` | Primary keyword, near front |
| `<h1>` | Primary keyword, natural phrasing |
| First 100 words | Primary keyword, naturally |
| `<h2>` tags | Secondary and LSI keywords |
| Image `alt` text | Descriptive, keyword-adjacent |
| Internal link anchor text | Exact or partial match |

### 3.3 Content Length Guidelines

| Page Type | Minimum Words | Optimal Range |
|---|---|---|
| Blog (educational) | 1,200 | 1,500–2,500 |
| Blog (how-to) | 800 | 1,000–1,800 |
| Comparison page | 1,500 | 2,000–3,000 |
| Use case page | 600 | 800–1,200 |
| Resource page | 400 | 500–800 |
| Doc page | 300 | 400–1,000 |

### 3.4 Image SEO

- All images have descriptive `alt` text
- File names follow the pattern: `expense-tracker-for-freelancers.png` (hyphenated, keyword-rich)
- WebP format where possible
- Maximum 200KB per image (enforced at build)

## 4. JSON-LD Schema System

Every page type has a mandatory schema. This directly feeds AI discovery.

### 4.1 Blog Posts

```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "{title}",
  "description": "{description}",
  "author": {
    "@type": "Organization",
    "name": "Money OS",
    "url": "https://moneyos.webasthetic.in"
  },
  "publisher": {
    "@type": "Organization",
    "name": "Money OS"
  },
  "datePublished": "{publishDate}",
  "dateModified": "{updatedDate}",
  "mainEntityOfPage": "{canonicalUrl}",
  "image": "/og/{slug}.png"
}
```

### 4.2 Documentation Pages

```json
{
  "@context": "https://schema.org",
  "@type": "TechArticle",
  "headline": "{title}",
  "description": "{description}",
  "about": {
    "@type": "SoftwareApplication",
    "name": "Money OS",
    "applicationCategory": "BusinessApplication"
  },
  "datePublished": "{publishDate}",
  "dateModified": "{updatedDate}"
}
```

### 4.3 FAQ Pages / Sections

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "{question}",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "{answer}"
      }
    }
  ]
}
```

Every blog post, comparison page, use case page, and resource page includes FAQPage schema. FAQ sections are the #1 AI crawler citation source.

### 4.4 Software Application (Homepage + Use Cases)

## 5. Core Web Vitals Targets

| Metric | Target | Strategy |
|---|---|---|
| LCP | < 2.5s | Static generation, no server latency, preloaded hero images |
| CLS | < 0.1 | Explicit image dimensions, no layout-shifting ads |
| INP | < 200ms | Minimal JavaScript (Astro zero-JS default) |
| FCP | < 1.8s | Inlined critical CSS, no render-blocking scripts |

Astro's default zero-JS architecture makes these targets achievable without optimization.

## 6. Crawl Budget Management

At 5,000+ pages, Google allocates a fixed crawl budget per day. Strategy:

- **Priority crawl**: `/docs/`, `/comparisons/`, `/use-cases/` (highest conversion value)
- **Last crawl**: `/resources/` (supplemental)
- **Never crawl**: `/super-admin/`, `/dashboard/`, `/admin/`, `/api/auth/`, `/api/internal/` — excluded via the main app's `robots.ts` `Disallow` rules (the app surface requires authentication, so no indexable content renders to crawlers)

Implement `<meta name="robots" content="index, follow">` on all discovery pages.

## 7. Page Speed Optimization

### Astro Optimizations (built-in)
- Zero JavaScript by default
- CSS is inlined at build time
- Fonts preloaded
- Images lazy-loaded natively

### Custom Optimizations
- All third-party scripts (PostHog, GA) are `async` and loaded after LCP
- Fonts served from `public/fonts/` — no Google Fonts CDN round trips
- OG images pre-generated at build time — no on-demand generation latency

## 8. Link Equity Strategy

### Internal Link Flow

```
Homepage → Category Pages → Individual Articles → Related Articles → CTA
```

Every article must link to:
1. At least one `/docs/` page (product credibility)
2. At least one related blog post (time on site)
3. One use case or comparison page (funnel movement)

### Anchor Text Diversity
- 40% exact match: "`expense tracker for freelancers`"
- 40% partial match: "`track expenses`" or "`freelancer finance tool`"
- 20% branded: "`Money OS`" or "`try Money OS`"
